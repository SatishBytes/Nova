# NOVA Frontend

The NOVA frontend is a React application built with Vite. It uses Supabase Authentication and connects to the Express API.

## Local development

1. Copy `.env.example` to `.env` and set the Supabase project URL, publishable key, and API URL.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.

The app is served at `http://localhost:5173` by default. Run `npm run build` to create a production build and `npm run lint` to check the source.
